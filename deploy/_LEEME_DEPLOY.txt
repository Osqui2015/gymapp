PASOS EN EL SERVER  (~/domains/gym.tecnorexs.com/public_html)
----------------------------------------------------------------------
0) BACKUP DEL CODIGO (antes de tocar nada)
   cd ~/domains/gym.tecnorexs.com/public_html
   tar -czf ~/backups/app_pre_p0_$(date +%Y%m%d_%H%M).tar.gz \
        app database/migrations public .env
   ls -lh ~/backups/app_pre_p0_*.tar.gz

1) MOVER EL BUILD VIEJO ASIDE  (te sirve de rollback del frontend)
   mv public/build public/build.bak.$(date +%Y%m%d_%H%M)

2) DESCOMPRIMIR ACA
   tar -xzf deploy_p0_20261029.tar.gz -C .

3) MIGRACION  (crea el indice UNIQUE, repara fechas, fusiona duplicados)
   php artisan migrate --force
   php artisan migrate:status
   # esperado: 2026_10_29_000000_fix_historials_idempotencia_y_fecha ... DONE

4) CLAVES VAPID  (rota la clave que estaba quemada en el git)
   php artisan webpush:vapid --no-interaction
   php artisan webpush:vapid --show

5) CACHES  (optimize:clear PRIMERO: si hay config:cache sigue la key vieja)
   php artisan optimize:clear
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
   chmod -R 775 storage bootstrap/cache

ROLLBACK
----------------------------------------------------------------------
   # frontend viejo
   rm -rf public/build && mv public/build.bak.XXXXXX public/build
   # codigo viejo
   tar -xzf ~/backups/app_pre_p0_XXXXXX.tar.gz
   # migracion
   php artisan migrate:rollback --step=1
   php artisan optimize:clear
   # datos (el rollback de migracion NO recupera las filas fusionadas)
   mysql -u USUARIO -p NOMBRE_DB < ~/backups/gymapp_pre_p0_XXXXXX.sql


NO HACER EN EL SERVER
----------------------------------------------------------------------
   - NO npm ci / NO npm run build (public/build/ ya viene compilado)
   - NO db:seed / NO db:seed --class (sin --class duplica usuarios e historiales)
   - NO migrate:fresh / NO migrate:refresh (borra la base)
   - NO php artisan storage:link (exec() esta deshabilitado en Hostinger;
     el symlink se crea a mano: ln -s ../storage/app/public public/storage)

TRAS EL DEPLOY
----------------------------------------------------------------------
   - Los usuarios que ya tienen la app instalada en el celu necesitan
     Ctrl+Shift+R / recargar fuerte, o cerrar y abrir la PWA: el service
     worker subio a VERSION v5 para tirar la cache vieja de favicon/iconos.
   - Si hay Cloudflare: Dashboard > Caching > Purge Everything.
