  `public_html` como `public_html_backup_t3`.

--------------------------------------------------------------------------------
3. LIMPIAR CACHES DE LARAVEL  (OBLIGATORIO, ANTES de cualquier artisan)
--------------------------------------------------------------------------------

    cd ~/domains/gym.tecnorexs.com/public_html

    php artisan config:clear
    php artisan optimize:clear

  Por que es obligatorio: si quedo una `config:cache` vieja con una
  `DB_PASSWORD` desactualizada, Laravel ignora el `.env` y cualquier
  comando artisan que toque la DB muere con:
      Access denied for user ... (using password: YES)


--------------------------------------------------------------------------------
4. VERIFICAR (no hay migraciones que aplicar)
--------------------------------------------------------------------------------

    php artisan migrate:status | tail -5      # las 62 migraciones deben decir Ran
    php artisan schedule:list                  # debe listar 5 tareas
    grep "const VERSION" public/sw.js         # debe decir const VERSION = 'v7'
    php artisan audit-logs:purge --days=365   # dry-run: no borra nada

  Resultado esperado de `schedule:list`:
    - membresias:actualizar-estados   00:05
    - db:backup                       02:00
    - reminders:send                  09:00
    - plateaus:detect                 10:00
    - audit-logs:purga                03:30   <- NUEVO


--------------------------------------------------------------------------------
5. CRON DEL SCHEDULER (PENDIENTE DESDE LA TANDA ANTERIOR)
--------------------------------------------------------------------------------

  Si ya lo configuraste en la Tanda 2, no hay que tocar nada.
  Si NO lo configuraste, es OBLIGATORIO: sin cron no corre ninguna tarea
  (ni el backup diario de la base, ni la purga de audit_logs).

  Hostinger -> cPanel -> Cron Jobs -> una entrada POR MINUTO:

    * * * * * cd /home/u221495434/domains/gym.tecnorexs.com/public_html && /usr/bin/php artisan schedule:run >> /dev/null 2>&1


--------------------------------------------------------------------------------
6. CACHES FINALES
--------------------------------------------------------------------------------

    php artisan config:cache
    php artisan route:cache
    php artisan view:cache

  (view:cache es importante: cambio las vistas de navegacion.)


--------------------------------------------------------------------------------
7. CLOUDFLARE + PWA
--------------------------------------------------------------------------------

  1. Cloudflare -> Cache -> Purge Everything
  2. Los usuarios con la PWA instalada necesitan recargar fuerte (Ctrl+Shift+R)
     o cerrar y reabrir la app: el service worker v7 cachea /icons/* y
     /favicon.ico con CacheFirst (URLs estables, sin hash).
  3. El banner "Nueva version disponible" ahora SI deberia aparecer.


--------------------------------------------------------------------------------
8. SI ALGO FALLA: ROLLBACK
--------------------------------------------------------------------------------

  El build viejo es el rollback:

    cd ~/domains/gym.tecnorexs.com/public_html
    # (si guardaste public/build.bak.<fecha>, restaurar)
    php artisan optimize:clear

  Y restaurar el backup de la DB si hizo falta (solo si corriste algo que
  escribiera en la base; esta tanda no tiene migraciones, asi que la DB
  deberia estar intacta).
